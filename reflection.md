1. Vad är skillnaden mellan Git och GitHub?

Git är versionshantering på dator medan github är webbplatsen där man sparar/delar Git-projekt

2. Varför är det bra att utveckla funktioner i separata branches?

Separata brancher gör att du kan jobba utan att förstöra main, och andra kan granska innan det slås ihop

3. Vad är skillnaden mellan git commit och git push?

commit = spara lokalt
push = skicka dina commits upp till GitHub

4. Vad är en Pull Request och varför använder man den?

En PR är ett "förslag" på att slå ihop en branch. Det används för granskning av kod innan kod hamnar i main

5. Vad kan hända om flera utvecklare ändrar samma fil samtidigt?

Merge conflict!!
Det kan bli en såkallad merge conflict, vilket innebär att Git vet inte vilken ändring som gäller, och detta måste lösas manuellt

6. Vad är skillnaden mellan git pull och git merge?

pull = hämta + slå ihop från remote till din branch
merge = slå ihop två branches (ofta lokalt)
